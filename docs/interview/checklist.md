# 投递与面试 Checklist

> 每次投简历前过一遍第一节，每次面试前过一遍第二节。
> 全部可勾选，别当参考资料读——**逐条打勾**才算过。

## 一、投递前（每次改简历都要过）

- [ ] 项目名统一：`广告投放管理平台与多智能体优化系统`（不要出现 `afs-cms` 这种内部代号）
- [ ] 时间区间真实：个人项目就写个人项目，别包装成公司项目
- [ ] 所有数字能在 `project-map.md` 找到出处（245 / 52 / 42 / 63 / 32 / 640 / 8 / 8 / 31）
- [ ] 没有写「358 条提交」（历史里 300 条是脚本生成的记录）
- [ ] 没有写「ROAS +40% / CPA −28%」这类合成数据结果
- [ ] 没有写「精通 Java / 精通 Spring」（改成「熟练掌握」，控制提问范围）
- [ ] 技术栈拼写正确：`LangGraph4j 1.5.14`、`LangChain4j 1.0.1`、`Spring Boot 2.7`
- [ ] 每条 bullet 是「动作 + 机制」，不是「使用了 XX 技术」
- [ ] 简历里提到的每个技术，都能答出 3 个追问（自查见 `qa-collection.md`）
- [ ] 岗位关键词对齐：JD 写了「Agent / RAG / 高并发」，简历里至少有 1 条对应
- [ ] PDF 导出后检查：中文不丢字、代码字体正常、超链接可点
- [ ] 文件命名：`姓名-Java后端-3年.pdf`（别用 `简历最终版v3.pdf`）

## 二、面试前 24 小时

面试官如果让你现场跑，你要保证**当场是绿的**。命令与期望输出：

```powershell
$env:JAVA_HOME='C:\Users\hwj11\.jdks\ms-17.0.20.1'
mvn -B clean test
# 期望结尾：Tests run: 31, Failures: 0, Errors: 0, Skipped: 0
#           BUILD SUCCESS
```

- [ ] 31 个用例全绿（10 个测试类：图端到端、护栏、检查点、鉴权、双人审批、海外运营等）
- [ ] 若 `clean` 失败提示无法删除 `target/afs-cms.jar`：先停掉正在跑的本地服务（jar 被占用）
- [ ] `mvn package -DskipTests` 能出 `target/afs-cms.jar`（≈194 MB fat jar）
- [ ] 能说出每个测试类**测的是什么**（见 `project-map.md` §2.4 的表，直接背）

## 四、现场必守的四条纪律

1. **先说结论，再说理由**：面试官时间有限，「我觉得是 A，因为 B、C」比铺垫半天更受欢迎。
2. **每个设计都要说代价**：「我选了检查点整图快照，代价是 state_json 会膨胀」——
   能说代价的人，才是真的做过决定的人。
3. **不会就说不会**：`「这块我没落地，我的理解是……，项目的做法是……」` 比编一个答案安全。
4. **主动标注边界**：合成数据、未上线、没有评估集——先说，比被问出来强。

## 五、五个高频翻车点（提前打预防针）

| 翻车点 | 触发场景 | 正确应对 |
| --- | --- | --- |
| 数字对不上 | 「你说 52 个 Controller，具体哪 52 个？」 | 说「按 `*Controller.java` 统计 52 个，含 `publicapi` 包的 11 个」 |
| 把合成数据当业绩 | 「ROAS 提升 40% 是怎么测的？」 | 「那是合成工作区的仿真结果，不是真实业务；真实效果无法在本环境证明」 |
| 吹 MD5 安全 | 「MD5 不是被攻破了吗？」 | 「是，它是存量契约的摘要算法；新接口会用 HMAC-SHA256 + Redis nonce」 |
| 假装有 RAG | 「你的向量库用的什么？」 | 「没有向量库，情景记忆是结构化 SQL，近 5 次审批记录」 |
| 说「没有难点」 | 「这个项目最难的地方？」 | 用 S5（检查点接入）或 S8（数据边界）回答 |

## 六、红线清单（写了就废）

- ❌ 把开源项目/教程项目说成自己主导的（GitHub 历史一查就穿）
- ❌ 编造团队规模、带人经历、上线用户量
- ❌ 编造性能指标（QPS / P99 / 并发数）
- ❌ 简历时间与社保/背调冲突（个人项目别写成在职经历）

## 七、面试后 30 分钟（很多人不做，但最值钱）

- [ ] 记下被问住的问题（按「完全不会 / 答得不深 / 答得乱」分类）
- [ ] 当天补掉「完全不会」的那 1-2 个知识点（记忆保鲜期只有 24 小时）
- [ ] 如果面试官提到了团队的技术栈，回来补一个最小 demo
- [ ] 把这轮的新问题追加到 `qa-collection.md`（下次面试就能复用）

> 三轮面试后你会发现：**被问的问题高度重复，重复的那 20 个才是真正的考点。**
